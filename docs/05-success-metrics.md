# Success Metrics and Stop Conditions

| Metric | Target by day 30 | If missed |
|---|---|---|
| Adoption | Pilot managers use Daily Manager Briefing at least 3 to 4 days per week | Shorten the output and remove noisy sections |
| Meeting quality | At least three high-stakes meetings per manager use Meeting Prep Brief | Add stakeholder, project, or document context before running prep |
| Follow-through | Weekly Manager Review captures real open actions and people waiting | Refine prompt language around commitments and owners |
| Signal quality | Risk outputs include source evidence and confidence labels | Pause risk workflows if outputs feel speculative |
| Governance | No action occurs without explicit approval | Stop automation and rewrite approval boundaries |
| Scale readiness | Pilot managers ask to keep using or share the workflows | Stabilize before expanding |
