# Overview

`copilot-chief-of-staff-for-managers` is a practical pattern for using Microsoft 365 Copilot with managers.

## Core idea

Managers should not start by deploying many agents. They should start with one operating rhythm:

1. daily briefing
2. meeting prep
3. team commitments review
4. weekly manager review
5. safe scale-out

## Repository name

Recommended public repository name: `copilot-chief-of-staff-for-managers`.

This keeps the hook memorable while the content stays practical and manager-focused.

## What this repo avoids

- autonomous task execution on day one
- performance evaluation or employee scoring
- daily inbox obsession
- speculative people analysis
- broad knowledge-source access before permission review
- Copilot Studio before the workflow is proven
